# Security policy

This repository is a best-effort reference sample, not a supported production service. No version receives guaranteed security updates.

| Version | Support |
| --- | --- |
| Latest default branch | Best-effort review |
| Earlier versions | Not supported |

Use the repository's **Security** tab → **Report a vulnerability** to submit a private report. Do not post exploit details in a public issue. Maintainers will review reports when available and coordinate disclosure after a fix is ready; no response or fix timeline is guaranteed.
